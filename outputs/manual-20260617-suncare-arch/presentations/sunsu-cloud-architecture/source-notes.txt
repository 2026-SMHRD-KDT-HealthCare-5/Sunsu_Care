Project facts used:
- Frontend: React 19 + Vite SPA.
- Backend: Node.js + Express API server on port 4000.
- AI service: Python FastAPI service on port 8001.
- AI pipeline: image preprocessing, YOLOv8 detection, CLOVA OCR, ingredient matching, compatibility scoring.
- Persistence: MySQL tables for users, profile, upload, product, ingredient, analysis, analysis log, and cache.
- Upload flow: Express receives authenticated image upload, records tb_upload, calls FastAPI with internal bearer token, receives callback, stores analysis/log rows.
- Recommendation flow: Express calculates top products and uses Gemini service with file cache fallback/cooldown behavior.
